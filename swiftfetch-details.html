SwiftFetch Download Manager

An open-source, IDM-style download manager for Windows — no paid services, no accounts, no telemetry

Key Features

Segmented Downloads

Files are split into up to 32 byte ranges fetched in parallel and written at their offsets into a pre-allocated file.

Pause & Resume

Per-segment progress is saved next to the file, so a paused, crashed or rebooted download continues where it stopped.

Download Queue

Configurable concurrency, retries with exponential backoff, a global token-bucket speed limit, and pause/resume all.

Chrome / Edge Extension

Manifest V3 extension that captures browser downloads with cookies and referer, adds a right-click menu entry, and lists media on the page.

Video Downloads via yt-dlp

Paste a video page URL, pick a quality or audio-only, and the bundled yt-dlp runs as a job with live progress, pause, resume and cancel.

Organized Folders

Downloads are sorted into Videos, Audio, Images and Files by extension or content type, with editable folder rules.

Tray & Startup

Keeps running in the system tray, can start with Windows minimized, and sends a desktop notification when a download finishes.

Local-Only Bridge

The extension talks to the app over a loopback HTTP API that only accepts extension origins, so web pages cannot push downloads into the app.

A Free Download Manager, Built From Scratch

SwiftFetch is an open-source download manager for Windows in the spirit of Internet Download Manager. It accelerates large downloads by splitting them into parallel byte ranges, survives pauses and crashes through per-segment resume state, and manages everything through a queue with concurrency and bandwidth controls.

The Electron main process hosts the download engine, settings and a loopback bridge for the browser extension, while the React renderer provides the queue, add dialog and settings UI. Everything in the stack is free and open source, with no accounts, paid services or telemetry.

Tech Highlights

  • Engine: Custom segmented HTTP downloader with range probing and resume files
  • Queue: Persistent job list, scheduler, retries and token-bucket limiter
  • Renderer: React with Vite and hot reload in development
  • Extension: Manifest V3 for Chrome and Edge, loopback API on port 47831
  • Media: yt-dlp, Deno and ffmpeg fetched on demand from official releases
  • Packaging: NSIS installer via electron-builder, desktop and Start Menu shortcuts
